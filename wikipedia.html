Temel Özellikleri

CSS Styling

✏️ SEN YAZACAK: CSS ÖZELLİĞİ
İzekip UI'ın CSS desteğini anlatır. Web geliştiricilerin CSS'i nasıl kullandığını, hangi selector'ları desteklediğini yaz. Qt'nin QSS'den farkını söyle.

GPU Rendering

✏️ SEN YAZACAK: GPU RENDERING
DirectX 11 ve Vulkan backend'lerini anlatır. İkisinin de aynı pixel output ürettiğini söyle. Cross-platform desteğini vurgula.

Flexbox Layout

✏️ SEN YAZACAK: FLEXBOX
Yoga motorunu kullanan layout sistemini anlatır. Responsive design yapabilmeyi söyle.

SDF Metin Rendering

✏️ SEN YAZACAK: METIN
stb_truetype ile SDF metin rendering. Türkçe karakter desteğini söyle.

Kod Örnekleri

Basit Buton Örneği

C++ Kodu:

auto root = std::make_shared<Widgets::Panel>();
root->SetId("root");

auto button = std::make_shared<Widgets::Button>();
button->AddClass("primary");
root->AddChild(button);

Css::StyleSheet sheet = Css::StyleSheet::LoadFromFile("style.css");
Css::LexborBridge bridge;
bridge.Build(*root);
Css::StyleApplier::Apply(bridge, sheet, *root);

CSS Kodu:

Button.primary {
    background: linear-gradient(to right, #3366FF, #5588FF);
    border-radius: 8px;
    width: 120px;
    height: 40px;
    transition: all 300ms ease-in-out;
}

Button.primary:hover {
    opacity: 0.8;
    box-shadow: 0px 6px 18px #00000070;
}
✏️ SEN YAZACAK: KOD AÇIKLAMASI
Bu kod ne yapar? Panel oluşturuluyor, buton ekleniyor, CSS yükleniyor ve uygulanıyor. Cümlelerle anlatır.
