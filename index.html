Temel Özellikler

📝

Gerçek CSS

Web geliştiricilerin bildikleri CSS dilini kullanan arayüz stilleri. Type selectors, class selectors, descendant combinators.

.button { background: linear-gradient(...); }
⚡

GPU Rendering

DirectX 11 (Windows) ve Vulkan (Cross-platform) ile hızlı ve güzel arayüzler. Pixel-perfect output her iki backend'de aynı.

D3D11 | Vulkan = Identical Output
📐

Flexbox Layout

Facebook'un Yoga motorunu kullanan responsive design. flex-direction, justify-content, align-items desteği.

flex-direction: row; justify-content: center;
✨

Smooth Animasyonlar

CSS transition ile cubic-bezier easing. background-color, width, height, opacity, margin animasyonları.

transition: all 300ms ease-in-out;
🎨

Görsel Efektler

border-radius (SDF), box-shadow, linear-gradient, backdrop-filter (blur, brightness, contrast, saturate).

border-radius: 8px; box-shadow: 0 4px 12px;
📄

SDF Metin

Modern SDF (Signed Distance Field) teknolojisi ile temiz metin. Türkçe karakter desteği (ş, ğ, ı, İ, vb.).

Label.title { font-size: 24px; }

Kod Örnekleri

Basit Buton (Button + CSS)

C++ Kodu

auto root = std::make_shared<Widgets::Panel>();
root->SetId("root");
root->AddClass("container");

auto button = std::make_shared<Widgets::Button>();
button->AddClass("primary");
root->AddChild(button);

// CSS'i yükle ve uygula
Css::StyleSheet sheet = Css::StyleSheet::LoadFromFile("style.css");
Css::LexborBridge bridge;
bridge.Build(*root);
Css::StyleApplier::Apply(bridge, sheet, *root);

CSS Kodu

Panel#root.container {
    background-color: #F5F5F5;
    width: 800px;
    height: 600px;
    flex-direction: column;
    justify-content: center;
    align-items: center;
}

Button.primary {
    background: linear-gradient(to right, #3366FF, #5588FF);
    border-radius: 8px;
    width: 120px;
    height: 40px;
    opacity: 1.0;
    transition: all 300ms ease-in-out;
}

Button.primary:hover {
    opacity: 0.8;
    box-shadow: 0px 6px 18px #00000070;
}

Desteklenen CSS Özellikleri

Layout & Boyutlandırma

  • width (px, %)
  • height (px, %)
  • margin (1-4 value shorthand)
  • padding (1-4 value shorthand)
  • flex-direction (row, column)
  • justify-content (center, flex-start, ...)
  • align-items (center, flex-start, ...)

Renkler & Fills

  • background-color (hex, rgb, rgba, named)
  • background: linear-gradient(...)
  • color (metin rengi)
  • border-color
  • opacity (0-1)

Görsel Efektler

  • border-radius (SDF)
  • box-shadow (multi-shadow)
  • backdrop-filter (blur, brightness, ...)

Animasyonlar

  • transition (property duration easing)
  • cubic-bezier() custom easing
  • Animatable: background-color, width, height, margin, opacity

Selectors

  • Type selectors: Button { }
  • Class selectors: .primary { }
  • ID selectors: #root { }
  • Descendant: Panel > Button { }
  • Pseudo-classes: :hover, :active, :focus

Scope Kararları (Henüz Yok)

  • flex-wrap, text-wrap
  • transform, perspective
  • font-weight, font-family
  • Position (absolute, relative)
  • z-index (paint order = tree order)
  • CSS Grid (flexbox only)

Build & Kurulum

# Windows - DirectX 11 (Default)
mkdir build
cd build
cmake .. -G "Visual Studio 18 2026" -DIZEKIP_RENDER_BACKEND=D3D11
cmake --build . --config Release

# İlk defa build'i çalıştır
.\Release\IzekipUIExample01.exe
# Vulkan SDK'yı ayarla (eğer env var set değilse)
$env:VULKAN_SDK = "C:\VulkanSDK\1.4.363.0"

# Build dizini oluştur
mkdir build-vulkan
cd build-vulkan

# CMake'i Vulkan ile configure et
cmake .. -G "Visual Studio 18 2026" -DIZEKIP_RENDER_BACKEND=VULKAN

# Build et
cmake --build . --config Release

# Çalıştır (her iki backend aynı output'u vermiş olmalı)
.\Release\IzekipUIExample01.exe
