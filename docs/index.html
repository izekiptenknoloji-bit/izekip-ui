İzekip UI: Linux kurulumu

Pardus / Debian üzerinde derleme ve örnekleri çalıştırma. Her komutu kopyalayıp terminale yapıştırın.

Her bloktaki komutlar sırayla çalıştırılır ve aynı terminal açık kalmalıdır. Bir adım hata verirse ilk error: satırını ve birkaç üst satırı geliştiriciye iletin.

1Kaynak kodu çekin

Daha önce klonlamadıysanız:

git clone --recurse-submodules https://github.com/izekiptenknoloji-bit/izekip-ui.git
cd izekip-ui

Zaten klonlanmış bir klasörde güncelleme için:

cd izekip-ui
git pull
git submodule update --init --recursive

2Gerekli paketleri kurun

sudo apt update
sudo apt install -y build-essential cmake git libgl-dev libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev libwayland-dev libxkbcommon-dev mesa-vulkan-drivers vulkan-tools

3LunarG Vulkan SDK (zorunlu)

Shader derleyicisi (dxc) bu SDK'nın içinde gelir. Önce vulkan.lunarg.com adresinden x86_64 tar.xz dosyasını indirin, ardından:

cd ~/Downloads
tar xf vulkansdk-linux-x86_64-*.tar.xz -C "$HOME"
source "$HOME"/*/setup-env.sh
echo "VULKAN_SDK=$VULKAN_SDK"

Son satırda bir yol görmelisiniz. Boşsa adımı tekrarlayın. Yeni bir terminal açarsanız bu satırı yeniden çalıştırın.

4Derleme

cd ~/izekip-ui
cmake -S . -B build-linux -DCMAKE_BUILD_TYPE=Release -DIZEKIP_RENDER_BACKEND=VULKAN -DIZEKIP_BUILD_TESTS=ON
cmake --build build-linux -j"$(nproc)"

5Testler

ctest --test-dir build-linux --output-on-failure

6Örnekleri çalıştırın

Örnekler bir pencere açar. Masaüstü oturumu olan bir ekrandan çalıştırın (SSH olmaz).

./build-linux/examples/01_basic_panel_button/IzekipUIExample01
./build-linux/examples/02_text_document/IzekipUIExample02
./build-linux/examples/03_notepad/IzekipUIExample03
./build-linux/examples/04_glassmorphism/IzekipUIExample04

7Pencere açılmazsa: Vulkan sürücüsü

vulkaninfo --summary

Çıktıda en az bir deviceName satırı olmalı. Hiç yoksa çıktının tamamını kaydedin.
