NativeCSS Framework

NativeCSS Framework is a C++ software library for building graphical user interfaces in desktop applications. It uses Yoga for widget layout and Lexbor to process CSS-like style rules.[1]

Architecture

An interface is represented as a tree of widgets. Each widget owns a Yoga node and may contain child widgets; layout results are resolved into absolute coordinates. The repository includes a base widget, panels, buttons and text labels. Widgets can be assigned a type name, identifier and classes, and hit testing can find the topmost widget at a given position.[2]

The graphics backend is selected when configuring the project with CMake. Separate renderer implementations are provided for Direct3D 11 and Vulkan. The shared renderer interface defines frame, drawing, presentation and resize operations, separating widgets from a particular graphics API.[3]

Programming interface

The principal classes and calls are grouped below by their role. [7]

Widget tree and drawing

  • IzekipUI::Widget — base class for interface elements.
  • AddChild, SetId, AddClass — add child widgets and assign identifiers or classes used by CSS selectors.
  • CalculateLayout, GetLocalRect — calculate layout and retrieve widget geometry.
  • OnPaint, HitTest — paint the widget tree and find a widget at a coordinate.
  • IzekipUI::Widgets::Panel, Button, Label — built-in widget types. Label text is managed with SetText and GetText.
  • SetHovered, SetActive — set widget interaction state.

CSS

  • StyleSheet::LoadFromFile, LoadFromString — load a stylesheet from a file or string.
  • LexborBridge::Build — prepare the widget tree for CSS selector matching.
  • StyleApplier::Apply — apply matched styles to the widget tree.

Renderer

  • IzekipUI::Render::IRenderer — shared interface for graphics backends.
  • CreateRenderer, GetCompiledInBackend — create a renderer and query the backend selected at build time.
  • Initialize, BeginFrame, EndFrame, Present, Resize — renderer lifecycle and resize operations.
  • DrawRect, DrawTextQuad — draw rectangles and glyphs.

Window and events

  • IzekipUI::Platform::Window, WindowDesc — window object and initial configuration.
  • PollEvents, ShouldClose — process window events and query its close state.
  • SetResizeCallback, SetCursorPosCallback, SetMouseButtonCallback — register window and mouse event callbacks.

Styling and layout

Stylesheets are parsed with Lexbor. The framework supports widget type, class and identifier selectors, grouped selectors, descendant selectors, and the supported interaction states :hover and :active. Matching declarations are combined according to specificity; unsupported CSS properties are not applied. [4]

The implemented style subset includes background and text colors, width, height, border color and width, font size, margin and padding. Lengths accept pixel units or unitless numbers. Margin and padding support the one-, two-, three- and four-value shorthand forms. Layout properties include flex direction (row, column and their reverse forms), justify-content and align-items; these are forwarded to Yoga nodes.[4]

Visual styling includes corner radius, solid backgrounds, two-stop linear gradients and drop shadows. Gradients use one of four cardinal directions. A transition declaration can specify one property or all, together with a duration and a named easing function. The source currently animates background color, width, height and margin. [4][2]

Rendering and text

Rectangles are rendered through a shared shader. Fill, gradient, rounded corner and shadow calculations operate in pixel space; color composition uses premultiplied alpha. The Direct3D 11 and Vulkan backends share HLSL shader logic; for Vulkan, the shader is compiled to SPIR-V. [5]

Text is rendered as individual quads sampled from a single-channel signed distance field (SDF) atlas generated from a TrueType font. Glyph advances and pair kerning are used for text measurement and placement. The atlas is built for the basic printable ASCII range (32–126), so it does not provide full Unicode font coverage.[5]

Scope and limitations

NativeCSS Framework is not a web browser or an engine for displaying arbitrary HTML documents. Lexbor is used to process CSS selectors against a C++-defined widget tree, and only a subset of CSS properties is applied. Full CSS standards support should not be assumed. [4]

A build selects a single graphics backend. D3D11 is the default CMake option; selecting Vulkan requires the Vulkan package and the DXC compiler component.[3]

Development

The project is configured with CMake and requires C++20. Build options control whether example applications and tests are built. The repository contains a panel-and-button example and CSS tests covering selector matching, specificity, interaction states, transitions and multi-value margin declarations.[1] [6]

NativeCSS Framework, C++ ile geliştirilen ve masaüstü uygulamalarında grafik kullanıcı arayüzleri oluşturmayı amaçlayan bir yazılım kütüphanesidir. Proje, arayüz bileşenlerinin yerleşimi için Yoga'yı; CSS benzeri stil kurallarının işlenmesinde ise Lexbor'u kullanır.[1]

Mimari

Arayüz, widget adı verilen bileşenlerden oluşan bir ağaç biçiminde tanımlanır. Her widget kendi Yoga düğümünü ve çocuk bileşenlerini taşır; yerel arayüz koordinatları yerleşim hesabından sonra mutlak koordinatlara dönüştürülür. Projede temel widget altyapısının yanı sıra panel, düğme ve metin etiketi bileşenleri bulunur. Widget'lar tür adı, kimlik ve sınıf bilgisi alabilir. Ayrıca ağaç üzerinde hit-test ile imleç konumuna denk gelen en üstteki bileşen bulunabilir.[2]

Kullanılacak grafik arka ucu CMake yapılandırması sırasında seçilir. Kaynak kodunda Direct3D 11 ve Vulkan için ayrı renderer uygulamaları bulunmaktadır. Ortak renderer arayüzü kare başlangıcı, çizim, sunum ve yeniden boyutlandırma işlemlerini tanımlar; arayüz bileşenleri bu sayede belirli bir grafik API'sine doğrudan bağlanmaz.[3]

Programlama arayüzü

Başlıca sınıflar ve çağrılar, kullanım alanlarına göre aşağıda gruplandırılmıştır.[7]

Widget ağacı ve çizim

  • IzekipUI::Widget — tüm arayüz bileşenlerinin temel sınıfı.
  • AddChild, SetId, AddClass — çocuk widget ekleme ve CSS seçicilerinde kullanılan kimlik/sınıf bilgilerini ayarlama.
  • CalculateLayout, GetLocalRect — yerleşim hesabı ve widget geometrisini alma.
  • OnPaint, HitTest — çizim ve koordinatla widget bulma.
  • IzekipUI::Widgets::Panel, Button, Label — hazır bileşen türleri. Etiket metni SetText ve GetText ile yönetilir.
  • SetHovered, SetActive — widget'ın etkileşim durumunu ayarlama.

CSS

  • StyleSheet::LoadFromFile, LoadFromString — stil sayfasını dosyadan veya metinden yükleme.
  • LexborBridge::Build — widget ağacını CSS seçici eşleştirmesine hazırlama.
  • StyleApplier::Apply — eşleşen stilleri widget ağacına uygulama.

Renderer

  • IzekipUI::Render::IRenderer — grafik arka uçlarının ortak arayüzü.
  • CreateRenderer, GetCompiledInBackend — renderer oluşturma ve derlemede seçilen arka ucu öğrenme.
  • Initialize, BeginFrame, EndFrame, Present, Resize — renderer yaşam döngüsü ve pencere boyutu işlemleri.
  • DrawRect, DrawTextQuad — dikdörtgen ve metin glifi çizme.

Pencere ve olaylar

  • IzekipUI::Platform::Window, WindowDesc — pencere nesnesi ve başlangıç yapılandırması.
  • PollEvents, ShouldClose — pencere olaylarını işleme ve kapanış durumunu sorgulama.
  • SetResizeCallback, SetCursorPosCallback, SetMouseButtonCallback — pencere ve fare olayları için geri çağrılar tanımlama.

Stil ve yerleşim

Stil dosyaları Lexbor kullanılarak ayrıştırılır. Kütüphane, widget türü seçicilerinin yanında sınıf ve kimlik seçicilerini, gruplandırılmış seçicileri, alt öğe seçicilerini ve desteklenen etkileşimli :hover ile :active durumlarını uygular. Eşleşen bildirimler özgüllüklerine göre birleştirilir; bilinmeyen veya desteklenmeyen CSS özellikleri uygulanmaz.[4]

Stil alt kümesinde arka plan ve metin rengi, genişlik, yükseklik, kenar rengi ve kalınlığı, yazı boyutu, kenar boşluğu ve iç boşluk gibi özellikler yer alır. Boyut değerleri piksel birimiyle veya birimsiz sayıyla ifade edilir; kutu kenarları için CSS'in tek, iki, üç ve dört değerli kısa yazımları desteklenir. Yerleşim özellikleri arasında flex yönü (row, column ve tersleri), justify-content ve align-items seçenekleri bulunur. Bu değerler Yoga düğümlerine aktarılır.[4]

Görsel stiller arasında köşe yarıçapı, tek renkli arka plan, iki renk duraklı doğrusal gradyan ve gölge bulunur. Gradyanlar dört ana yönü kullanır; gölgeler yatay ve dikey kaydırma, bulanıklık yarıçapı ve renk alır. Geçiş bildirimi tek bir özellik veya all için süre ve adlandırılmış easing seçeneği tanımlayabilir. Kaynak kodunda arka plan rengi, genişlik, yükseklik ve kenar boşluğu geçişleri yer alır. [4][2]

Çizim ve metin

Renderer, dikdörtgenleri ortak bir gölgelendirici üzerinden çizer. Dolgu, gradyan, yuvarlatılmış köşe ve gölge hesapları piksel uzayındaki dikdörtgenler üzerinden yapılır; renk karışımı önceden çarpılmış alfa yaklaşımını kullanır. D3D11 ve Vulkan arka uçları aynı HLSL gölgelendirici mantığını kullanır; Vulkan yapılandırmasında gölgelendirici SPIR-V biçimine derlenir.[5]

Metin bileşeni, TrueType yazı tipinden üretilmiş tek kanallı imzalı uzaklık alanı (SDF) atlasındaki karakterleri ayrı dörtgenler halinde çizer. Karakter ilerleme genişlikleri ve çiftler arası kerning bilgisi metin ölçümünde ve çiziminde kullanılır. Atlas temel yazdırılabilir ASCII aralığına (32–126) göre oluşturulur; bu nedenle Unicode metninin tamamı için kapsamlı yazı tipi desteği olduğu anlamına gelmez. [5]

Kapsam ve sınırlamalar

NativeCSS Framework, HTML belgelerini yerleşim motorunda görüntüleyen bir web tarayıcısı değildir. Lexbor, widget ağacına bağlı CSS seçicilerini ve kurallarını işleme akışında kullanılır; arayüzün yapısı C++ widget nesneleriyle oluşturulur. Uygulanan CSS özellikleri projenin kendi alt kümesiyle sınırlıdır; tam CSS standardının desteklendiği varsayılmamalıdır. [4]

Derleme sırasında yalnızca tek grafik arka ucu seçilir. CMake yapılandırmasında varsayılan seçenek D3D11'dir; Vulkan seçeneği için Vulkan paketi ve DXC derleyici bileşeni aranır.[3]

Geliştirme

Proje CMake ile yapılandırılır ve C++20 standardını gerektirir. Derleme seçenekleri örnek uygulamaları ve testleri açıp kapatmaya imkân verir. Depoda panel ve düğme kullanan bir örnek ile seçici eşleştirme, özgüllük, etkileşim durumları, geçiş bildirimi ve çok değerli kenar boşluğu gibi konuları kapsayan CSS ayrıştırıcı testleri bulunur.
