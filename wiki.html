İzekip UI, 2026 yılında Furkan tarafından geliştirilmeye başlanan açık kaynak C++ grafik arayüz (GUI) kütüphanesidir. Qt kütüphanesine daha basit ve web geliştiricileri için daha uyumlu bir alternatif sunmayı hedeflemektedir. Gerçek CSS (Cascading Style Sheets) stil desteği, GPU tabanlı hızlı rendering (DirectX 11 ve Vulkan) ve Facebook'un Yoga flexbox motorunu kullanarak modern, responsive arayüzler oluşturmaya imkan verir.

Neden Yapılmıştır?

Qt kütüphanesinin karmaşık yapısı ve öğrenilmesinin güç olması, İzekip UI'ın geliştirilmesinin temel nedenlerindedir. Qt'nin MOC (Meta-Object Compiler) pre-compiler'ı, Signal/Slot mekanizması ve karmaşık CMake kurulumu, yeni başlayanlar için ciddi bir engel oluşturmaktadır.

Öte yandan, web geliştiricileri CSS (Cascading Style Sheets) dilini çok iyi bilmektedirler. Eğer GUI arayüzleri de CSS ile tasarlanabilirse, öğrenme eğrisi çok daha eğimli hale gelir. İzekip UI tam da bu ihtiyacı karşılamak için geliştirilmiştir: C++ ile mantık ve veri yapıları, CSS ile stil ve tasarım.

Ayrıca modern GPU'ların (Graphics Processing Unit - grafik kartları) gücünden tam olarak faydalanmak, pure GPU rendering (saf GPU render) ile Windows (DirectX 11), Linux ve macOS (Vulkan) arasında pixel-perfect (piksel-mükemmel) aynı görüntü oluşturmak hedeflenmektedir.

Temel Özellikleri

CSS Styling

İzekip UI'ın en ayırt edici özelliği gerçek CSS (Cascading Style Sheets) dilini kullanmasıdır. Bu, web geliştiricilerin CSS'i ve W3C web standartlarını doğrudan C++ GUI geliştirmeye aktarmasını sağlar. Desteklenen CSS selectors'ları arasında type selectors (Button, Panel), class selectors (.primary, .large), ID selectors (#root), descendant combinators (Panel > Button) ve pseudo-classes (:hover, :active, :focus) bulunmaktadır. Renk formatları (hex #FF6B6B, rgb, rgba, adlandırılmış renkler), boyutlandırma birimleri (px, %) ve flexbox properties desteği mevcuttur.

GPU Rendering

İzekip UI sadece GPU (Graphics Processing Unit) kullanarak rendering yapar, yazılım rendering (software rendering) kullanmaz. Bu, hızlı ve keskin grafiklerin oluşturulmasını sağlar. İki farklı backend desteği mevcuttur: DirectX 11 (Windows native GPU API) ve Vulkan (Khronos standardı, cross-platform). Önemli bir özelliği, her iki backend'in pixel-identical (piksel-aynı) output üretmesi ve görüntü kalitesinin farksız olmasıdır.

Flexbox Layout

Facebook'un geliştirdiği Yoga layout motorunu kullanan responsive (uyumlu) design desteği sunmaktadır. flex-direction (row, column), justify-content (flex-start, center, space-between) ve align-items (flex-start, center, stretch) gibi flexbox properties ile modern, ekran boyutuna uyumlu arayüzler oluşturabilir.

SDF Metin Rendering

stb_truetype kütüphanesi kullanılarak TrueType fontları SDF (Signed Distance Field) teknolojisi ile 512x512 piksellik texture'a dönüştürülür. Bu yöntem, zoom'lanırken bile temiz ve keskin yazı görüntüsü sağlar. Türkçe karakter desteği (ş, ğ, ı, İ vb.) yapılmıştır.

Proje Mimarisi

Proje yapısı net bir şekilde public API (include/) ve implementation (src/) ayrımı yapılmıştır. include/Core/ klasöründe Widget, animasyon ve layout matematikleri; include/CSS/'de CSS parser ve style uygulayıcı; include/Renderer/'da GPU abstraction interface bulunmaktadır. Implementation dosyaları src/ altında benzer yapıda organizedir. third_party/ klasöründe GLFW, Yoga, lexbor ve stb_truetype gibi bağımlılıklar vendored (satın alınmış/dahil edilmiş) şekilde bulunmaktadır. Render backend'leri (src/Renderer/D3D11/ ve src/Renderer/Vulkan/) private implementasyonlar olarak kalır ve public API'den gizlidir. Şader kodu (RectShader.hlsl) her iki backend tarafından paylaşılmaktadır.

Geliştirme Aşamaları (Phases)

Phase 1: MVP (Minimum Viable Product)

İlk aşamada GLFW penceresi, DirectX 11 device ve swap chain, hand-rolled CSS parser (sadece type/.class/#id selectors), Yoga layout engine ve düz renkli dikdörtgen rendering oluşturulmuştur. examples/01_basic_panel_button örneği bu aşamayı temsil etmektedir.

Phase 2: Interactive UI

GLFW mouse/cursor callbacks, Widget::HitTest (hit detection), hover state management ve :hover/:active CSS pseudo-classes eklenmişdir. CSS transition özelliği ile cubic-bezier easing engine (Newton-Raphson solver) uygulanarak smooth animasyonlar (renk, boyut, margin) sağlanmıştır.

Phase 3: Visual Effects

border-radius (SDF shader ile yuvarlak köşeler), box-shadow (gölge efekti), linear-gradient (geçişli renkler) ve premultiplied alpha blending eklenmişdir. Bu özellikler henüz animate edilmemektedir (snap-only).

Phase 4: Vulkan Backend

DirectX 11'e paralel olarak ikinci IRenderer implementasyonu olan Vulkan backend geliştirilmiştir. SPIR-V shader compilation (build-time dxc), Vulkan surface creation, swapchain management ve validation layer testing yapılmıştır. Test makinesi Intel UHD Graphics ile Vulkan 1.4'ü kullanmış ve D3D11 ile pixel-identical output alınmıştır.

Phase 5: Standards-Compliant CSS

Hand-rolled CSS parser'ı lexbor kütüphanesine geçilmiştir. Descendant combinators (> operatörü), multi-value CSS shorthands (margin: 10px 20px 30px 40px), flex-direction/justify-content/align-items Yoga'ya wiring yapılmış ve proper CSS cascade ile specificity uygulanmıştır.

Phase 6: Text Rendering (SDF)

stb_truetype ile glyph rasterization, 512x512 SDF atlas texture, RectShader.hlsl'e text mode flag, Widgets::Label (single-line text), Yoga'nın YGNodeSetMeasureFunc ile font sizing, Latin-1 + Turkish extended characters ve D3D11 + Vulkan texture/sampler support eklenmiştir.

Phase 7: TextArea & Keyboard (Devam Ediyor)

Widgets::TextArea (multi-line editable), TextBuffer data structure, keyboard event handling, Platform::Window callbacks, :focus pseudo-class ve cursor positioning aşaması devam etmektedir. examples/03_notepad örneği bu aşamayı göstermektedir.

Kod Örnekleri

Basit Buton Örneği

C++ Kodu:

// Widget ağacı oluştur
auto root = std::make_shared<Widgets::Panel>();
root->SetId("root");
root->AddClass("container");

auto button = std::make_shared<Widgets::Button>();
button->AddClass("primary");
root->AddChild(button);

// CSS yükle ve uygula
Css::StyleSheet sheet = Css::StyleSheet::LoadFromFile("style.css");
Css::LexborBridge bridge;
bridge.Build(*root);
Css::StyleApplier::Apply(bridge, sheet, *root);

CSS Kodu:

Panel#root.container {
    background-color: #F5F5F5;
    width: 800px;
    height: 600px;
    flex-direction: column;
    justify-content: center;
    align-items: center;
}

Button.primary {
    background: linear-gradient(to right, #3366FF, #5588FF);
    border-radius: 8px;
    width: 120px;
    height: 40px;
    opacity: 1.0;
    transition: all 300ms ease-in-out;
}

Button.primary:hover {
    opacity: 0.8;
    box-shadow: 0px 6px 18px #00000070;
}

Bu örnek, kök panelin (açık gri background, centered layout) ve gradient butonun (mavi gradyan) oluşturulmasını göstermektedir. Buton hover'da opaklik azalır ve gölge çıkar. 300ms boyunca smooth transition ile animasyon yapılır.

Qt ile Karşılaştırma

Özellik Qt İzekip UI
Öğrenme Eğrisi Dik Eğimli
Styling Dili QSS (özel syntax) CSS (Web standartı)
Widget Sayısı 100+ ~5 (minimal)
Rendering Software + GPU hybrid Pure GPU
Cross-Platform ✅ Tam desteklenen 🔄 Windows + Vulkan devam
C++ Standard C++11+ C++20
Setup Karmaşıklığı Ağır, kompleks Hafif, CMake basit
Hedef Kitle Genel amaçlı Web dev'ler

Qt, geleneksel "tüm şeyi C++ kodunda yapmak" yaklaşımı izlerken, İzekip UI web paradigmasını kullanır: "C++ ile logic, CSS ile style". Bu, web geçmişi olan geliştiriciler için çok daha doğal ve öğrenmesi kolaydır. İzekip UI'ın minimal widget seti ve pure GPU rendering'i onu hafif ve hızlı kılmaktadır.

Platform Desteği

Şu Anda Test Edilen

Windows 10/11: DirectX 11 backend'i tam desteklenmektedir (MSVC 2026 ile derlenir). Vulkan backend de test edilmiş ve çalışmaktadır (Vulkan SDK 1.4.363.0). Build tools'lar arasında Visual Studio 2026, CMake 4.3.1 ve Windows SDK 10.0.26100.0 bulunmaktadır.

Planlanmış

Linux ve macOS: Vulkan backend'i için altyapı hazır olmasına rağmen, henüz native test ve doğrulama yapılmamıştır. Cross-platform Vulkan desteği nedeniyle, Linux ve macOS'ta Vulkan backend'i çalışması beklenmektedir.

Katkı Alanları

Aşağıdaki alanlarda katkılar açık olarak kabul edilmektedir:

  • CSS özellik desteği (backdrop-filter enhancements, yeni özellikler)
  • Yeni widget türleri (Checkbox, Select, Slider)
  • Performans optimizasyonu (batching, invalidation tracking)
  • Linux/macOS native testing ve doğrulama
  • Dokümantasyon ve örnek uygulamalar

İnce Kararlar (Intentional Scope Cuts)

Qt'nin Signal/Slot mekanizması bilerek çıkarılmıştır. Minimal widget seti tercih edilmiş, 100+ widget yerine ~5 widget kullanılmıştır. Absolute positioning ve z-index henüz uygulanmamıştır (flexbox only).
